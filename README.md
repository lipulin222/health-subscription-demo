## 页面内容

- 顶部：状态栏 / 导航「线上服务」
- 健康订阅卡 → 科学减重服务卡（点右上角状态胶囊循环切换 5 个阶段）
  1. 购前科普：快速了解跑马灯 + 效果/安全/花费/使用 四分类 + 双按钮
  2. 决策：方案已生成 + 进度 + 知识库入口
  3. 陪跑：数据行 + 进度条 + 知识库入口
  4. 续费：提醒卡（可切换 8 条提醒 / 问 AI 助理）+ 数据行 + 知识库入口
  5. 维持期：24 周数据带 + 双按钮
- 其他专项入口标签：减重 / 过敏 / 痤疮 / 心理
- 下方：线上问诊、视频心理咨询、家庭私人医生、底部 tab（沿用设计稿，未改动）
