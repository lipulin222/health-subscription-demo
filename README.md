# 健康订阅区 Demo · health-subscription-demo

线上服务首页「健康订阅」区块 + 体重管理服务卡的可交互 Demo。

- 线上预览：https://lipulin222.github.io/health-subscription-demo/
- 来源：现网首页设计稿 `卓正-线上服务-方案1.html`（MasterGo file/134385500956539 · page 3229:77533）
- 卡片逻辑：移植自 `online-health-care` 的减重服务卡，现为 **6 阶段状态机**
- 视觉：按《健康订阅区 · 视觉规范》校准（字号五档 / 圆角三档 / 青色系 / 对比度达标）

## 页面内容

- 顶部：状态栏 / 导航「线上服务」
- 健康订阅卡 → 体重管理服务卡（右上角状态胶囊循环切换 6 个阶段）
  1. 未开始：科普跑马灯 + 分类入口 + 快速评估
  2. 报告已生成：方案匹配度 + 科普入口 + 双按钮
  3. 进行中：体重与进度 + 陪伴内容（支持「还没有记录」的初始空态）
  4. 续费：单条提醒卡 + 数据行 + 续药 / 随访分流
  5. 维持期：24 周数据带 + 双按钮
  6. 开启日：「减重旅程开启！」+ 猜你想问 +「记录第一天」（呼起原生日期选择器）
- 右上角「⋯」切换新客 / 老客状态；深链 `?stage=1~6`、`?state=new|old`
- 其余专项入口：减重 / 过敏 / 痤疮 / 心理；下方为线上问诊、视频心理咨询、家庭私人医生、底部 tab

## 子页面

首诊评估、评估报告、用药套餐、支付、预约就诊、订单记录、科普知识库、月报、询问护士（AI 助理）、随访评估等，见仓库根目录各子目录。

## 本地预览与维护

- 建议起本地静态服务后访问 `index.html`；页面依赖 `shared.js`、独立 CSS/JS 与 `design-assets` 图片，**不是单文件页面**（`file://` 直开时部分脚本与网络请求不可用）。
- 全站统一口径（价格、商品名、疗程周数、声明文案）集中在 `shared.js` 的 `ZZ.CFG`，改价只需改一处；`ZZ.money()` 统一金额格式。
- 图片已按手机壳 2 倍图降采样，页面里的 `<img>` 默认 `loading="lazy" decoding="async"`。
